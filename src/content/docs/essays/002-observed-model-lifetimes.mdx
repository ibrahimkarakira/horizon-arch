## The numbers

Measured from a model version's release to the vendor's deprecation notice for it, over n = 76 model versions from three vendors: median 302.5 days, quartiles 196 and 414.5 days. Half of the versions got their notice within about ten months of release; a quarter got it within 196 days.

- Shortest: 58 days (`gemini-omni-flash-preview`, line 109)
- Longest: 818 days (`gpt-4o-mini-2024-07-18`, line 37)

The rows come from each vendor's deprecation page,[^anthropic][^openai][^google] with missing release or notice dates taken from the vendor's own release notes. Rows missing either date are left out, not estimated: 36 of the 112 rows. The method is on [Model lifetimes from public vendor pages](/framework/model-lifetimes/).

## What the data cannot say

- **It is not the time to retirement.** The measure ends at the deprecation notice. Retirement comes later, by a margin each vendor sets; Anthropic, for example, promises at least 60 days' notice for publicly released models.[^anthropic]
- **It is biased short.** Only models that already have a notice are counted. A model still on sale without one has lived at least its age so far, and leaving it out pulls the median down.
- **It describes three vendors in 2023 to 2026.** 76 versions, 39 of them Google's, do not make a constant of the field, and the vendors' policies can change.
- **Row counting follows the vendor's IDs.** A vendor that ships one family as many IDs (preview, stable, size variants) gets more weight than one that ships a single ID.
- **The preview split is a string match.** An ID counts as a preview when it contains `preview`; a model that is a preview in all but name counts as stable.
- **Vendors edit these pages.** The access date on every row says which version was read; a retirement a page no longer lists is not in the data.
