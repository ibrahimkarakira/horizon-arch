An AI system is more than its model. Six layers make it up, and each can change without the others: the model, the instructions and prompts, the tool and API interface, the data and memory, the evaluation assets, and the human process around it.

</figure>

How long each layer lasts, and how to measure it, is the subject of [Model Half-Life](/framework/model-half-life/).
