# horizon-arch v0.1.0

First tagged release. The site builds and previews locally, the prediction format is checked on every run, and the Model Half-Life framework page has its first dataset. No prediction is published yet, so the scoreboard shows its empty state.

## What is in it

- **Site.** A Starlight site with the home page, the scoreboard, the diagram convention, the Model Half-Life framework page and the model lifetimes page.
- **Prediction format.** A zod schema, a generated JSON Schema for editors and `templates/prediction.yml`; `npm run validate` checks every file in `predictions/`.
- **Scoreboard.** `npm run scoreboard` writes counts by horizon and status, the Brier score with its n and the upcoming checkpoints; the page renders them, with an empty state.
- **Conventions.** Diagram rules (captions, alt text, palette) and a sourcing policy whose footnote format `npm run check:sources` enforces on published pages.
- **Model lifetimes.** `data/model-lifetimes.csv` holds 112 model versions from the Anthropic, OpenAI and Google deprecation pages; `node scripts/model-halflife.mjs` prints n = 76 and a median of 302.5 days from release to deprecation notice.

The full list, with issue links, is in `CHANGELOG.md` under 0.1.0.

## Try it

```sh
git clone https://github.com/ibrahimkarakira/horizon-arch
cd horizon-arch
npm ci
npm run check
npm run preview
```

Node 22 (see `.nvmrc` and `engines` in `package.json`). `npm run check` runs lint, build, tests, the prediction validator and the source checker, and stops at the first failure. `npm run preview` serves the built site on `http://localhost:4321`.

## Not in this release

- No public site: the hosting choice is open, so v0.1.0 runs locally only.
- No published prediction, essay or reference architecture. Those start in v0.5.0.
